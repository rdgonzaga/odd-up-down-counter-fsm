# CSARCH HDL 2

A repository for HDL 2 of CSARCH1.

- **Circuit (given):** Odd up-down binary counter
- **Model type:** Behavioral (state diagram method)
- **Inputs:** `Y`, `reset`, `clock`
- **Output:** `count[3:0]`

## Counter Behavior

- **If `reset == 0`:** `count = 0001` (regardless of `Y`)
- **If `reset == 1` and `Y == 1` (upstream):**
  `0001 -> 0011 -> 0101 -> 0111 -> 1001 -> 1011 -> 1101 -> 1111 -> 0001 -> ...`
- **If `reset == 1` and `Y == 0` (downstream):**
  `1111 -> 1101 -> 1011 -> 1001 -> 0111 -> 0101 -> 0011 -> 0001 -> 1111 -> ...`

## Files

- `AGonR.v` - main behavioral odd up-down counter module
- `AGonR_tb.v` - testbench with required test cases and clock generation
- `AGonR.vcd` - waveform dump generated by simulation
- `simv` - compiled simulation artifact

## How to Run (Icarus Verilog)

From the project root:

```bash
iverilog -o simv AGonR.v AGonR_tb.v
vvp simv
```

This generates `AGonR.vcd` and prints monitored values in the terminal.

## View Waveform (GTKWave)

```bash
gtkwave AGonR.vcd
```

Add signals `Y`, `reset`, `clock`, and `count` to inspect transitions.
